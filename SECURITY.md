# Security Policy

## Supported Versions

Currently, only the latest major version (v5) of CDIE receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 5.x.x   | :white_check_mark: |
| < 5.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within CDIE, please do NOT open a public issue. Instead, please report it via private disclosure (e.g., email the maintainers or use GitHub Security Advisories).

We will investigate all legitimate reports and do our best to quickly issue a patch or provide a mitigation strategy.
